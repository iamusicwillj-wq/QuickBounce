## LAME 3.100

QuickBounce 使用 LAME 将 WAV 转换为 MP3。构建脚本从上游源码生成并静态链接 LAME。许可为 LGPL-2.0-or-later。

QuickBounce uses LAME for WAV-to-MP3 conversion. The build script compiles LAME from upstream source and QuickBounce links it statically. LAME is licensed under LGPL-2.0-or-later.

QuickBounce 通过 PTSL 与 Pro Tools 通信。源码构建所需的 SDK 由开发者向 Avid 获取，适用相应的 SDK 许可。

QuickBounce uses PTSL to communicate with Pro Tools. Developers obtain the SDK for source builds from Avid under the applicable SDK terms. [Avid Pro Tools Scripting SDK](https://developer.avid.com/scripting/)

## 系统组件 / System components

QuickBounce 使用 macOS 提供的音频、界面及 SQLite 组件。

QuickBounce uses the audio, UI and SQLite components provided by macOS.
